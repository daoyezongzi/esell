# 项目默认规则

这是从用户已确认流程提炼的默认配置，不是普遍选品定律。新任务的明确要求优先；没有必要每次重新询问这些默认值。

|项目|默认|
|---|---|
|范围|非拉线汽配、老商用车/货车、割草机等工作设备小型维修件；可按用户扩大到船艇等|
|Amazon|美国站，New York 10001，新品商品价至少20美元，不含运费|
|竞争|有效同款独立竞争不超过5，按限定且已完成的查询范围报告|
|常规需求|eBay单listing最近365天，新品、美国买家，销量严格超过20|
|需求例外|真实原厂身份＋较高价格＋真实成交依据；“高价”无统一数值，助手保存依据，用户最后确认，不自行新增金额门槛|
|货源|确认对应完整实物；真实报价、起订量和利润不作为助手交付前提|
|供应商偏好|优先河北；排除晶迪、荣富、北京文浩轩/文皓轩，不自行新增排除|
|人工阶段|最后复核、补外部缺数据、供应商询价及采购|

供需画像比类目名重要：具体设备仍有维修价值，准确接口/适配使通用件难替代，美国准确供给相对弱，国内可能已有完整货源。黄金样本只用来学习结构，不从少数成功样本推导整个类目盈利。

运行时输入应记录：用户范围和数量、时间预算、历史状态文件位置、平台可访问性、允许跳过项、硬门槛修改。不要默认缺少eBay数据就改用累计销量；也不要把某次平台不可用写成skill的永久禁用。

用户历史明确排除和经营数据留在用户工作区。skill仓库不需要账号会话、cookie、完整采购目录或历史报告才能运行；若未提供历史清单，公开说明去重覆盖有限。
