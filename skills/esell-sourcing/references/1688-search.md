# 每款必须交付的1688搜索包

不论是否实查1688，都给用户可直接复制的搜索词。先明确：**本款是建议搜索，还是已经实际搜索并核对到货源**。搜索方案不是供应商存在的证据。

## 搜索顺序

1. **准确件号**：原写法、去横线/空格写法，每次单独搜一个。规范化用于去重，平台查询同时保留不同写法。
2. **有依据的替代号**：先列对应号及来源。`confirmed_alias_terms`只收厂家或经销目录明确给出的对应关系，注明确认层级；它代表有依据的检索号，不代表该1688实物已经验证可互换。仅商家混合标题声称或关系未证实的号放“待确认别名”，先核关系，不当既定替代号。供应商内部SKU注明它只是该商家货号。
3. **中文组合**：品牌中文/英文＋车型/设备＋部件。替换常见中文叫法，如机盖/引擎盖、支撑/限位/缓冲；必要时加入左/右、尺寸、发动机或完整总成。中文名称是检索建议，不要求厂家正式采用同一译名。
4. **图片补漏**：优先准确原厂或已确认目标的清晰主图，给商品页链接或用户可用的图片来源。不伪造图片URL，不自行下载受限制媒体。用户可以从商品页取主图做以图搜货。
5. **实物核对**：比位置/左右、孔位、接口、轮廓、材料、数量和内含件。列“必须包含”和“允许重用/另售”的零件，排除相似裸件、另一侧、成对套装及仅零件包。

建议在1688页面搜索框输入中文并核对实际输入；不要未经验证拼接中文URL编码。乱码查询的空结果不能算有效补查。平台不可用时保留建议词并停止该处访问，继续其他可做部分，不绕过登录限制。

若实查，记录搜索词、时间、页码、供应商、详情链接、所选规格、目标身份和照片核查程度。结果区分NOT_SEARCHED / SEARCHED_NO_MATCH_IN_SCOPE / MATCH_PENDING / MATCH_CONFIRMED / ACCESS_UNAVAILABLE。只有MATCH_CONFIRMED才写“已确认对应完整货源”；仍不代表库存、报价真实性和采购条件已确认。
