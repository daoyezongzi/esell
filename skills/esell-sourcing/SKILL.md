# ESell 维修配件选品

交付少量有证据、可继续核查的具体维修件，并让用户拿到结果后知道如何在1688找准确货源。筛选通过、人工待核、未做完和已排除必须分开。

## 选择本次模式

- **新选品**：外部发现 → 去重 → 实物身份 → 市场预筛 → 优先候选深查 → 1688搜索交接。
- **继续/复核**：读该款上次证据、状态和查询位置，只补缺口，不从头搜索。
- **只问1688怎么搜**：使用已知候选直接生成搜索包，未知替代号不猜。没有实查就写“建议搜索，尚未确认货源”；不强制重跑市场。
- **方法测试**：分开报告规则回放、新线索发现、实际深查及人工复核，不能把任一层代替全部流程。

先读取 [项目默认规则](references/profile.md)，将用户本轮范围、门槛、时间预算、可访问平台和历史排除覆盖进去。不要把历史会话中一次登录失败、测试跳过1688或某个机器路径写成永久规则。需要浏览器时，使用当前环境提供的获授权浏览器能力和对应使用说明。

## 执行顺序

1. **发现具体维修件。** 从新的厂家目录、经销商、零售商品等外部来源取得准确件号、品牌、用途、适配和原始链接。复制黄金样本的供需结构：设备仍有人修、型号明确、替代供给弱；不把样本已有型号再当新品。
2. **去重。** 读取用户提供的状态表、已有/已下单及明确排除清单；搜索确认别名及带/无横线写法。历史只用于去重，不作新品来源。同号命中后核品牌、用途和实物，跨行业撞号不排除。缺少历史资料就写“去重未完成”，不声称全新。
3. **固定实物。** 核车型/设备、年份或序列号、发动机/规格、左右侧、数量、完整内含件、接口，以及需要重用的配件。准确同款、功能替代、不同包装、明确不同和待核分别标注。文字、图片、原厂目录的核验程度分开。
4. **分层预筛。** 优先核能改变决定的事实。明确失败及时停该款；未知不失败。站外低价仅是价格压力，不能直接代替Amazon价格门槛；成本未知不判无利润。
5. **只深入优先项。** 按 [市场覆盖和判定](references/market-checks.md) 核Amazon同款/卖家和eBay时间窗。每款由一位负责人收尾；只有已获授权且能独立分工时才开子代理，共享浏览器由一位操作者控制。
6. **每款都写1688搜索包。** 按 [1688搜索方法](references/1688-search.md) 提供件号写法、确认替代号、中文组合词、图片依据和实物检查点。这一步即使未登录1688也能完成；不能把“会搜”写成“已找到供应商”。
7. **保存并交接。** 使用 [输出约定](references/output-contract.md) 生成简短中文报告及需要持久化的候选JSON。每款附原始证据、已查范围、状态、具体缺项、责任人和下一步。默认正文突出前3款，余下放队列；用户要求更多则按其数量交付。

## 决策边界

- 保留默认门槛，用户本轮修改优先。缺数据留最后人工，不为缺项反复要求登录或停止整轮。
- 已有/已下单/用户明确排除不重推，不能通过换别名绕回。助手旧结论证据不足时保留历史并标待复核，不擅自恢复成新品。
- 年度未知不是0；20不满足超过20；累计sold、评价、库存、不同listing合计都不是单listing年销。
- 5个结果不是5家竞争，10个账号不是10家已证实独立企业；同ASIN重复广告、二手报价、左右套装不混算。
- 助手预算没做完用 `BUDGET_NOT_RUN` 留助手队列，不能冒充数据不可得。真正访问受限、未公开或用户允许跳过的项可交人工。
- `REVIEW_READY` 表示本次可查范围已完成、只剩明确人工项；`QUALIFIED_SCREENING` 才表示全部适用筛选关通过或用户明确接受例外。两者均不代表盈利或采购授权。
- 供应商联系、询价、MOQ确认和采购由用户处理。研究授权不包含发消息、下单或付费数据订阅。

## 省时与验证

在既定预算内，先完成少量候选，再扩发现。常用调度为1名主代理加至多2名已获授权的发现代理；约8分钟发现10条是历史测试量级，不是产出承诺或必须执行的配额。没有用户时间要求时选择适合任务规模的预算。

网页首次观察结构后，只返回决定性商品/报价字段；原始证据留本地。避免把导航、广告iframe属性、无关商品和整个历史库反复送入模型。记录查询词、分页、停止点，无新证据不重复空查询。

使用提供的 [示例JSON](assets/example-candidates.json) 理解字段，并运行：

```text
python scripts/validate_candidates.py <生成的候选JSON>
```

路径相对本skill目录；脚本只做离线结构和关键不变量检查，不证明事实真实、选品准确率或利润。输出报告前人工式复读决定性证据：身份有没有混、数量有没有错口径、1688词能否直接复制、是否误称已找到货源。
